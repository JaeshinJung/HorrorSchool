# Horror School (Unity 3D Horror Project)

A first-person psychological horror game built with a focus on **modular architecture** and **systematic asset management**. This project demonstrates an organized approach to game development, utilizing custom scripts and editor tools to streamline the creation of an immersive horror experience.

## 🚀 Key Technical Features

* **Systematic Project Architecture:** Utilized a numbered directory structure (`01Scenes` to `09Editor`) to maintain a highly organized and scalable project environment, reflecting industry-standard asset management.
* **Modular Scripting (`02Scripts`):** Developed decoupled C# scripts to handle player mechanics, environmental puzzles, and horror event triggers independently.
* **Custom Editor Tools (`09Editor`):** Implemented editor-side scripts to assist in level design and workflow optimization within the Unity environment.
* **Dynamic Animation & Sound:** Integrated synchronized animations (`03Anims`) and spatial audio (`06Sounds`) to enhance the psychological atmosphere and player immersion.

## 🛠 Tech Stack
* **Engine:** Unity
* **Language:** C#
* **Assets:** Custom Prefabs, Physic Materials, and TextMesh Pro for high-quality UI.
* **Development Focus:** Clean Code, Resource Organization, and State-based Logic.

## 📂 Directory Structure
* **01Scenes**: Main menu and core gameplay levels.
* **02Scripts**: All C# logic, including Game Management and Player Controllers.
* **04Prefabs**: Reusable game objects for efficient level building.
* **09Editor**: Custom editor scripts to enhance the development workflow.

## 📝 How to Explore
1. Open the project folder in **Unity Hub**.
2. Navigate to `01Scenes` and open the `Main Menu` or primary gameplay scene.
3. Review `02Scripts` for an in-depth look at the game's logic and architecture.
